显示器切换（macOS 版）  v@@VERSION@@
==================================

一、安装
  1. 解压后把「显示器切换.app」拖进「应用程序」文件夹。
  2. 第一次打开：在图标上点右键 →「打开」→ 再点「打开」。
     （程序没有 Apple 开发者签名，直接双击可能被提示"无法验证开发者"，
       右键打开一次之后就不会再提示。）

二、使用
  双击「显示器切换.app」，窗口标题会显示版本号，可选：
    · 切到 Mac       显示器切到 HDMI-1，显示 MacBook 的画面
    · 切到 Windows   显示器切到 DP，显示 Windows 主机的画面
    · 设置           登录后是否自动切到 Mac 画面

三、首次运行
  程序需要一个小工具 m1ddc 来跟显示器通信。
  第一次打开时会询问是否自动安装（需要联网，约 1 分钟）。
  自动安装失败就在「终端」里手动执行：
      brew install m1ddc

四、注意
  1. 显示器 OSD 菜单里的 DDC/CI 必须开启（AOC Q24G2 默认开启）。
  2. 如果 Mac 通过拓展坞的 HDMI 口连显示器，个别拓展坞不透传 DDC 通道，
     切换会失败。把 Mac 那根线改成 USB-C 转 HDMI 直连显示器即可。
  3. 切到 Windows 之后，Mac 会暂时"找不到外接显示器"，属正常现象。
     要切回来用 Windows 端那个程序，或按显示器机身上的 INPUT 键。
  4. 程序不常驻后台，执行完立即退出。

五、卸载
  1. 把「应用程序」里的「显示器切换.app」拖进废纸篓。
  2. 如果开过开机自启，删掉这个文件：
         ~/Library/LaunchAgents/com.monswitch.autostart.plist
     或在程序里点「设置 → 不自动切换」，会自动清掉。
  3. m1ddc 占空间很小，可留可删；要删就在「终端」执行：
         brew uninstall m1ddc
